# Causal-Analyst
Official implementation of "A Casual Perspective for Enhancing Jailbreak Attack and Defense"

# Implementation
Our work is based on the [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory) repository.

# How to use
1. First, use `download.sh` to download a LLM for subsequent training.
2. Then you can train a causal analyst simply by running `run_pipeline_comb.sh`
